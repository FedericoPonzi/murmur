# Platforms

| Platform | Status |
| --- | --- |
| Browser | Local developer probe; public alpha in development |
| Linux desktop app | Planned |
| Windows desktop app | Planned |
| macOS desktop app | Planned |
| Android native app | Planned |
| iOS native app | Planned |

There are no packaged desktop or mobile app downloads yet.
Native mobile apps and mobile browser compatibility are separate milestones.

Developers can build the [native Rust PoC](docs/quick-start.html) on Ubuntu or
run the [local browser probe](docs/browser-probe.html). Public HTTPS/WSS
deployment and broader browser support still need verification.
