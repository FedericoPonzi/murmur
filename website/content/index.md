# Murmur

Decentralized micro-blogging using [Veilid](https://veilid.com).
Authors share a RecordKey; readers use it to find their recent posts.

**Proof of Concept, not a production release.** You can run the native
read-only bridge or try a browser-hosted node locally. The browser alpha is
still being built.

[Explore the current app](app/index.html) or [read the documentation](docs/index.html).

## Take part

The browser probe can publish one disposable test post and read other feeds.
The native PoC supports continuing publication through its local CLI.

[How participation works](participate.html) and [available platforms](platforms.html).

Posts are public to anyone with the complete RecordKey. This is a recent-post
feed, not a permanent archive. Read the [limits and privacy notes](limitations.html)
before using it.
