# Participate

## Available now

Run the [native PoC](docs/quick-start.html) to host a read-only bridge and
publish through the local CLI. Readers can paste another author's RecordKey
into that bridge without creating an account.

The [browser probe](docs/browser-probe.html) runs its own Veilid node in a
worker. Create a local passphrase-protected identity, unlock it, read feeds,
and publish posts. Use disposable
identities and harmless public text.

## Planned browser alpha

Save follows, restore an identity, and download an
encrypted backup.

There will be no central account or password-reset service. The website will
not hold author keys or sign posts for visitors. Backup and recovery are
**not implemented yet**.

Native app downloads are [Planned](platforms.html).
