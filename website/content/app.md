# Browser application

The full browser application is in development. This preview does not create
identities or publish posts.

## Try the current probe locally

Follow the [browser probe guide](../docs/browser-probe.html) to build and serve
the separate developer UI. Start its node, wait for attachment, publish one
disposable test post, and read another feed by RecordKey.

The [native read-only bridge](../docs/quick-start.html) remains available
separately. Integrated browsing, a composer, and encrypted identity management
will arrive in subsequent increments.
